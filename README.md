Application to use Vencore on Android.

## ❓ About

Vencore Manager is an application that installs and updates [Vencore Mobile](https://github.com/ApexTeamPL/venmobile-bundle),
a modification for Discord. (fork of [Revenge](https://github.com/revenge-mod/))

## 💪 Features

Some of the features Vencore Manager provides are:

- 📲 **Install**: Download and install Vencore client!
- 🔌 **Update**: Update Vencore to the latest version
- 🔔 **Notifications**: Be notified when a new version of Revenge is available
- 🖥️ **Changelog**: See the changelog of Vencore (ig if it works...)
